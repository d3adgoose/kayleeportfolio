Dialogue System Guide

A setup and testing reference for placing dialogue conversations in a level using BP_DialogueTrigger. Conversations begin when the player enters a trigger and progress through an ordered list of dialogue lines.

Player interaction

  • Start: Walking into the dialogue trigger automatically starts the conversation.
  • Advance: Press E on keyboard or the dodge button on controller to advance one line per press.
  • Finish: Press interact while the final line is displayed to close the dialogue.
  • Active conversation only: Dialogue progression should respond to input only while a conversation is active.

The final line stays visible until the player presses interact again. “Automatically closes” means the conversation closes when there are no remaining lines after that press; no timed dismissal is specified.

Dialogue data and presentation

Each entry in DialogueLines contains the following fields:

SpeakerName
The name of the character speaking the current line, displayed in the dialogue UI.
DialogueText
The current line of dialogue shown in the dialogue box.
LeftPortrait
The character image displayed in the fixed left portrait position.
RightPortrait
The character image displayed in the fixed right portrait position.

Both portraits remain displayed on their respective sides during the conversation. For a conversation between the same two characters, assign the same left and right portraits to every line, including when the speaker changes.

Set up a conversation

  1. Place the trigger. Drag BP_DialogueTrigger into the level where the conversation should begin.
  2. Size the trigger area. Select DialogueTriggerBox and scale it to cover the area the player should enter to start dialogue.
  3. Add dialogue entries. Select BP_DialogueTrigger. In the Details panel, locate DialogueLines and press + for each line.
  4. Fill in every entry. Set SpeakerName, DialogueText, LeftPortrait, and RightPortrait. Arrange the entries in the order the player should read them.

Test in game

Use the following checks to verify the intended behavior:

  1. Press Play and walk into the trigger box. Confirm that dialogue appears automatically with the first line.
  2. Confirm that the speaker name, dialogue text, and both portraits match the configured entry.
  3. Press E once. Confirm that dialogue advances exactly one line. Repeat using the controller dodge button.
  4. Continue through the conversation. Confirm that portraits stay on their assigned sides when the speaker changes.
  5. With the final line visible, press interact once more. Confirm that the dialogue closes.
  6. After the conversation closes, press interact again. Confirm that inactive dialogue does not advance or reappear from that input.
Scope: trigger setup, dialogue data, input behavior, and expected test results. This guide does not specify trigger replay behavior, movement restrictions, branching choices, or input priority relative to dodge.
